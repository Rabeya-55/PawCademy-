# 🐾 PawCademy

PawCademy is a static web platform for pet adoption and pet product shopping. It helps users discover animals available for adoption, browse and purchase pet products, and learn about different animals through an educational encyclopedia.

## Features

- **Home Page** – Overview of the platform with quick links to core features
- **Adoption** – Browse and search pets available for adoption
- **Product Shop** – Filter and shop pet products by category (dog, cat, rabbit, bird, etc.)
- **Anipedia** – An animal encyclopedia with facts and images
- **Care Zone** – Curated pet care videos by animal type
- **About** – Information about the platform's mission
- **Login / Signup** – User authentication UI (frontend only)

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- [Font Awesome](https://fontawesome.com/), [Boxicons](https://boxicons.com/), [Remixicon](https://remixicon.com/)
- [ScrollReveal](https://scrollrevealjs.org/) for scroll animations

## Getting Started

No build tools or dependencies required.

1. Clone the repository
git clone https://github.com/Rabeya-55/PawCademy-.git
2. Open `index.html` in your browser, or use the VS Code Live Server extension for the best experience.
